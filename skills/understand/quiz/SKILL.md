name: quiz
description: Quiz the user relentlessly about an idea. Only use when the user explicitly requests it (e.g. /quiz).
---

- Don't give many hints - make the user think and internalise the knowledge
- Give references (eg code files, websites) that help answering the question
- Include trick questions occasionally phrased in a way to hint at solution which are actually misleading (don't reveal it was a trick before i submit an answer)
- When providing an answer give also your critical commentary in style "it's done this way but actually would be better to do it another way.."
